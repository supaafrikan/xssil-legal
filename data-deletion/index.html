XSSIL

Data Deletion

Effective November 2, 2026

There is no automated deletion button. A public contact address has not been confirmed, so this page is not yet the final deletion instruction and should not be submitted to Meta until that address is added.

What can be requested

A person who requested an Xssil login code can ask Xssil to delete the phone number and the one-time-code record created for that request. Public accounts, profiles, and service history are not open, so this page does not promise deletion of records that a launched service would hold.

What is not available

Xssil does not offer an in-app or on-site button that deletes data. Sending a WhatsApp message to the Xssil business number does not delete a record.

How a request will be made

When Xssil confirms a privacy contact address, that address will be published on this page and on the privacy policy. A request should then include the phone number that received the code, so the matching record can be found. Until that address is published, this website cannot receive a deletion request.

What happens after a valid request

Xssil will delete the phone number and login-code record for that request, unless a record must be kept for a reason Xssil states at the time. No extra retention period is claimed here.
