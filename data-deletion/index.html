XSSIL

Data Deletion

Effective November 2, 2026

There is no automated deletion button. Send a deletion request by email.

What can be requested

A person who requested an Xssil login code can ask Xssil to delete the phone number and the one-time-code record created for that request. Public accounts, profiles, and service history are not open, so this page does not cover records that a launched service would hold.

What is not available

Xssil does not offer an in-app or on-site button that deletes data. Sending a WhatsApp message to the Xssil business number does not delete a record.

How to ask

Email xssilrideshare@gmail.com. Include the phone number that received the code, so the matching record can be found. Use the subject “Xssil data deletion.”

What happens after a valid request

Xssil will delete the phone number and login-code record for that request. This page does not claim that any record is kept for an extra period.
