XSSIL

Privacy Policy

Effective November 2, 2026

This policy describes only what Xssil does today. Public services are not open. The legal entity name, registered address, and privacy contact address are not confirmed on this page yet. Do not treat this as the final policy until those details are added.

Who this covers

Xssil is preparing a platform for connecting people with services. The first intended market is Senegal, with later expansion to other countries. Those services are not available yet. This website does not offer them.

The only personal-data activity currently operating is a login-code test. A person can ask for a one-time code to be sent to a phone number on WhatsApp.

Information used for that test

When a code is requested, Xssil receives the phone number, creates a one-time code, and records whether that code is still unused, has been used, or has expired. The code expires after five minutes and works once.

Xssil does not ask for a name, address, or payment card on this website. This policy does not describe account profiles, location, messages, or payments for services, because those features are not publicly available.

Why the phone number is used

The phone number is used to send the login code and to check the code that is entered. It is not sold and it is not used here for advertising.

WhatsApp delivery

The code is delivered through Meta’s WhatsApp Cloud API from the Xssil Connect WhatsApp business account. Meta processes that message under Meta’s own terms and privacy policy. Xssil does not control WhatsApp’s separate processing.

Where the check is processed

The authentication check for the current test is hosted on Amazon Web Services in the United States. A phone number submitted for a code may therefore be processed in the United States, including when the person is in Senegal or another country.

How long the code is kept

The one-time code is kept only until it expires or is used, whichever comes first. Xssil has not adopted a longer retention period for public accounts, because public accounts are not open. This page will be updated before any longer retention is used.

Security

Access to the authentication service is limited to the operation of the login-code test. The code is not displayed in routine public pages. No security certification is claimed on this page.

Your request

You may ask what phone number and login-code record Xssil holds from a code you requested, and you may ask for that record to be deleted. There is no automated deletion button. The public address for those requests has not been confirmed. This page will be updated with that address before it is submitted to Meta as the final privacy policy. Until then, this website cannot receive a deletion request.

Changes

When this policy changes, the effective date above will change. The current page at this address is the version in effect.
